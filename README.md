# 日记批量总结（Daily Summary Batch Processor）项目

## 项目介绍

本项目是一个自动化工具，用于批量处理日期格式的 Markdown 日记文件，通过调用 AI API 自动生成日记概要，并将概要内容更新到日记文件的指定位置。

### 功能特点

- **批量处理**：自动扫描目录下所有符合日期格式（`YYYY-MM-DD.md`）的日记文件
- **智能识别**：自动检测日记是否已有概要内容，避免重复生成
- **AI 总结**：调用 AI API 生成日记概要
- **自动更新**：将生成的概要自动写入日记文件的指定位置
- **配置灵活**：支持通过配置文件自定义 API 参数、提示词、输出位置和批量发送数量
- **批量发送**：支持一次发送多篇日记给大模型，便于上下文关联分析
- **日志功能**：支持记录 API 调用日志，便于调试和追溯
- **格式兼容**：自动处理 Markdown 引用格式，适配不同渲染软件

### 适用场景

- 个人日记管理：为多篇日记自动生成摘要
- 知识整理：快速浏览日记内容概览
- 批量处理：一次性处理多篇日记文件

## 快速开始

### 面向使用者(使用exe文件)

1. **下载程序**：从 `dist/` 目录获取 `日记批量总结.exe`
2. **准备日记文件**：将符合 `YYYY-MM-DD.md` 格式的日记文件放在程序同一目录下
3. **配置 API**：编辑 `config.ini` 文件，填入您的 AI API 密钥
4. **运行程序**：双击 `日记批量总结.exe` 运行

### 面向开发者（从源码运行）

```bash

cd <项目目录>

source venv/bin/activate  # Linux/Mac

# 安装依赖
pip install -r requirements.txt

python main.py
```

## 配置说明

### config.ini 配置项

```ini
[ai]
url = https://api.longcat.chat/openai/v1/chat/completions  # AI API 地址
api_key = ak_your_api_key_here                               # 您的 API 密钥
model_name = LongCat-Flash-Chat                              # 模型名称
temperature = 0.2                                           # 生成温度（0-1，越小越稳定）

[prompt]
prompt = 请你以第三人称、客观中立的视角，为下面的日记生成一段不带有主观褒贬、不煽情、不做道德评判的简洁概要...

[output]
output_site = > [!NOTE] 概要                                  # 概要内容插入位置标记

[base]
count = 3                                                   # 每次发送给大模型的日记数量

[log]
log = true                                                  # 是否开启日志功能（true/false）
```

### 日记文件格式要求

日记文件需符合以下格式，程序会在 `> [!NOTE] 概要` 标记后插入生成的概要内容：

```markdown
#日记
## 基础数据
---
天气：晴
地点：北京

---
- [x] 已完成事项
- [ ] 待办事项

---

> [!NOTE] 概要
>

---
### ==感想：==


---
### ==记录：==
日记正文内容...
```

## 实现方法

### 处理流程

1. **读取配置**：从 `config.ini` 文件读取 API 配置和提示词
2. **扫描文件**：查找目录下所有符合 `YYYY-MM-DD.md` 格式的文件
3. **检测概要**：检查每个日记文件是否已有概要内容
4. **调用 API**：对无概要的日记调用 AI API 生成总结
5. **更新文件**：将生成的概要写入日记文件的指定位置

### 技术栈

- **Python 3.x**：主开发语言
- **requests**：HTTP 请求库，用于调用 AI API
- **configparser**：配置文件解析
- **pyinstaller**：打包工具，生成可执行文件

### 核心函数说明

| 函数 | 功能 |
|------|------|
| `read_config()` | 读取配置文件 |
| `get_md_files()` | 获取符合日期格式的 md 文件列表 |
| `call_ai_api()` | 调用 AI API 获取总结 |
| `update_md_file()` | 更新日记文件中的概要部分 |
| `format_summary()` | 格式化总结内容 |
